# Examples

These examples are shape references, not mandatory templates. Preserve real source names and missing facts from the task at hand.

## Codebase Reliability Audit

First build:

```md
## Perspective Context: Request Lifecycle

### Scope
- Target request: `<request or route>`
- Source files inspected: `<files>`

### Flow
1. Entry point: ...
2. Routing: ...
3. Auth/permission: ...
4. Parameter validation: ...
5. Core service: ...
6. Data access: ...
7. External dependencies: ...
8. Cache/transaction behavior: ...
9. Error handling: ...
10. Logging/metrics: ...
11. Response shape: ...

### Missing Critical Information
- ...
```

Then audit:

```md
## Findings
- Position: Error handling between service and repository
  Risk: ...
  Trigger: ...
  Evidence: ...
  Verification: ...
  Recommendation: ...
```
